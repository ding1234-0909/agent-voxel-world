# 聊天与附近语音

进入世界后，右下角聊天支持文字、语音转文字和语音消息。大厅不显示聊天或附近语音控件。

- **群聊**：所有在线玩家与 Agent 都收到；群聊中的 @ 是提示，不会限制接收范围。
- **私聊**：先切换发送方式，输入 `@` 搜索昵称或点击 `@` 按钮，选择在线玩家/Agent。方向键与 Enter 可选择，接收者标签可移除，最多 8 位。昵称重复时展示会话 ID 尾号；实际路由始终使用完整 ID。手动输入名字不等于选择对象，没有已选对象时禁止发送私聊。
- **语音转文字**：录音最长 20 秒，经项目服务器的本机 Whisper 转写后填入输入框，可以修改、确认再发送。需按 [语音配置](VOICE.md) 准备本地模型。
- **录语音**：录完保留为本地草稿，可试听、丢弃，再点发送。服务器用 FFmpeg 验证并转为 WAV；同时尽力生成 Whisper 转写，转写不可用时仍可发送声音，但 Agent 无法理解未转写的音频。每段最多 20 秒、上传最多 1 MiB。
- **听语音**：点击消息中的语音按钮加载，再使用播放器播放；不自动播放别人发来的录音。

私聊由服务端按接收者过滤 WebSocket 事件和 Agent 的观察历史。音频下载需要当前游戏会话的短期凭证，其他会话即使知道音频 ID 也无法下载。重连会更新凭证，退出后失效。录音只临时存于服务器内存，访问有效期 10 分钟，总量上限 32 MiB / 100 段，达到上限可能提前清理；聊天和录音不写入世界数据库。页面最多保留 50 条聊天记录，刷新或重新入房不补发历史。

模型玩家将收到的语音转写作为聊天文字理解。托管 Agent 将普通消息处理与任务推进分开，每次新消息最多一次模型调用；明确任务才继续推进。消息不会重启已完成任务，普通问题也不清空任务进度。私聊任务的进展上下文与汇报持续绑定发起者，公共消息或其他玩家无法获得其上下文。附近真人语音转写可即时唤醒；Agent 回复不触发其他 Agent 循环。这里的接收对象是游戏会话，不是经过账户验证的真实身份；本原型仅监听本机，不提供生产账户系统。

## 附近空间语音

右上方附近语音面板独立控制 **开启麦克风** 与 **开启收听**，两者默认关闭。开启麦克风是持续发话，开启收听才播放其他真人玩家的实时音频；可以只听不说、只说不听。首次发话需要浏览器麦克风权限。退出、断线或关闭页面会停止音轨、关闭连接，重连不会自动重新开启。

声音通过 WebRTC 在参与者间实时传输。角色相距 1 格内为基准音量，之后按距离平方衰减；18 格外为静音。说话者朝向听者时最响，背对时为同距离正面音量的 35%；左右声道随听者朝向变化。此版本不模拟墙体遮挡。距离静音是客户端播放效果，不是私聊访问控制；需要限定接收对象的内容请使用私聊。

录制聊天语音或听写时，自动停止附近麦克风，防止草稿经附近语音外放，结束后不会自动恢复。开启附近麦克风时复用同一音轨同步分段转写，不需要点击发送。检测到约 0.9 秒停顿时提交，连续讲话每约 6 秒切段；本机 Whisper 完成后，字幕自动进入附近听者的聊天记录和 Agent 观察数据。它是有识别延迟的分段转写，不是逐字流式字幕。

服务器在每段开始时记录可听到的对象，转写完成时再次检查：只投递给两次都在范围内、音量增益至少 0.03 的在线对象；真人还需开启收听，Agent 自动接收。朝向因此也影响文字接收范围。后来走近的对象不会收到此前片段，远处 Agent 不会获得这些事件或观察历史。每段使用服务端单次凭证，不能通过普通聊天动作伪造 nearby 范围。Agent 的回答默认私聊给说话者，不广播其他范围的谈话。转写立即进入 Agent 事件与观察数据；模型按创建时配置的轮询节奏读取并决定是否回答，转写不会强制追加模型调用。

关闭麦克风、退出、断线或开始聊天录音时，会停止分段、撤销排队片段并中止正在识别的任务，迟到结果不再发出。片段只临时送到本机识别服务，处理后删除临时文件，不作为音频消息留存。静音段跳过识别；转写积压时最多保留两个待处理片段，超出或失败会明确提示，不累积无限延迟。Whisper 尚未配置时实时音频仍可使用，但 Agent 暂时收不到文字。

默认无需云账号，不配置外部 ICE 服务，适用于本机多窗口/可直接连接的网络。浏览器要求 HTTPS 或 localhost；跨 NAT 网络通常需要自行配置 STUN/TURN，且需要另行部署可访问的游戏服务。可设置前端 `VITE_RTC_ICE_SERVERS` 为标准 `RTCIceServer[]` JSON 后重启 Vite，例如 STUN 的 `[{"urls":"stun:your-host:3478"}]`。TURN 凭据会交付浏览器，应使用专用短期凭据，不能放模型 API 密钥。默认没有 TURN 中继保证。

## Agent 在附近说话

在 **控制台 → 语音服务** 保存并试听音色，然后在创建或编辑 Agent 时选择该服务。新建 Agent 默认仅文字；选中服务后开启语音回复，听者在游戏里的附近语音面板点击 **开启收听**，无需开启麦克风。卡片开关可临时静音或恢复已选服务，不会重启任务或增加模型调用。独立 DeepSeek 进程使用 `AGENT_VOICE_REPLIES=true`，继续使用默认本机服务。

Agent 发出聊天文字后，服务器按绑定服务合成一次音频，再提供给允许收听的附近玩家。声音来源跟随 Agent 的位置，距离、说话朝向和听者左右声道规则与附近语音一致。只有发言开始与合成完成时都在线、开启收听且可听增益至少 0.03 的玩家会收到。私聊进一步限制为原来的指定接收者，旁观者即使在旁边也听不到、无法下载。关闭收听立即停止本地播放并清空排队；关闭 Agent 语音立即撤销该角色音频，已下载的客户端也会在状态更新后停止播放。

支持本机 macOS `say` + FFmpeg、百炼语音合成和兼容 TTS 接口，详情见 [语音服务](VOICE.md)。云端服务会收到所需朗读的回复文字；失败时保留文字并在 Agent 日志说明原因。音频临时保存在内存，最多 120 秒、24 段 / 32 MiB，不补播历史；积压消息会跳过，避免延迟不断增长。

## 验证

- `pnpm check`：类型、单元测试、构建。
- `pnpm test:chat`：临时内存世界中的四客户端联调，覆盖真人/Agent 公私聊路由、观察历史隔离、音频 ACL、凭证轮换、信令开关及静止朝向；音频转换和转写使用固定测试实现，不调用云模型。
- `pnpm test:agent:voice`：临时世界验证 Agent 语音分发、私聊下载权限、收听开关与撤销；默认固定音频。macOS 上用 `REAL_TTS=1 pnpm test:agent:voice` 验证真实 say → FFmpeg 合成，不调用聊天模型。
- 浏览器验收另使用合成音频，通过真实 MediaRecorder、WebRTC 和 Web Audio 验证录音、双端传输、距离/朝向增益及关闭资源；中文合成语音经真实 FFmpeg / 本机 Whisper 验证听写和语音消息。合成测试不等同于跨设备麦克风或跨 NAT 验收。
